# CSAC 2023 Survey Project 

## Project Description 

This is the code repository for the 2023 financial aid survey project conducted by California Education Lab in collaboration with the California Student Aid Commission (CSAC).
There are two waves for the survey: the first wave is a survey sent out to all graduating high school seniors who filed FAFSA, and the second wave in the fall for all current
college students who are FAFSA filers. 

This current branch /christina is the self-contained code repository created and maintained by Christina Sun. For current project repo, check /main branch. This branch corresponds to the /christina folder in the Scribe project folder.
